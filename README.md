# Baby shower de Luis Gael

Invitación web con animaciones al hacer scroll. Funciona como sitio estático, sin instalar dependencias.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Descomprime este ZIP y sube su contenido a la raíz del repositorio: index.html, assets, .nojekyll y README.md. No subas únicamente el ZIP.
3. En Settings > Pages selecciona Deploy from a branch.
4. Selecciona main y / (root), y guarda.
5. GitHub mostrará el enlace cuando termine la publicación.

## Editar

Abre index.html en un editor de texto. Contiene los textos, estilos y animaciones. Conserva la carpeta assets junto a index.html.

Datos incluidos: Luis Gael; sábado 21 de noviembre de 2026 (año pendiente de confirmación); 6:00 p. m. a 10:00 p. m.; Restaurante Nove; regalo en efectivo. El botón Cómo llegar abre la ubicación proporcionada.

Opcionales pendientes: nombres de los papás, número para confirmar asistencia y música. No se agregó un número ficticio.

Las tipografías se descargan desde Google Fonts; si no hay conexión, se usan fuentes alternativas. Las imágenes se incluyen en assets.
